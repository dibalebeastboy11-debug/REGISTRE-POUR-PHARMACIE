# PHARMA-REGISTRE PRO

Bienvenue sur **PHARMA-REGISTRE PRO**, une application web légère et intuitive conçue pour aider les pharmaciens à gérer leurs ventes quotidiennes, suivre leurs performances et maintenir un registre propre de leurs activités.

## 🚀 Fonctionnalités
- **Gestion des ventes :** Enregistrez vos ventes (médicaments, quantités, prix) en quelques clics.
- **Tableau de bord analytique :** Visualisez instantanément votre chiffre d'affaires du jour, de la semaine et du mois.
- **Personnalisation :** Configurez le nom de votre pharmacie, le nom du pharmacien et choisissez entre un thème clair ou sombre.
- **Sauvegarde et Export :** Exportez vos données en format JSON pour conserver vos archives en sécurité et importez-les si nécessaire.
- **100% Locale :** Vos données sont stockées directement dans votre navigateur, garantissant une rapidité optimale.

## 🛠 Installation
Il n'y a pas d'installation complexe ! Comme il s'agit d'une application web, elle s'exécute directement dans votre navigateur.

1. Téléchargez ou clonez ce dossier.
2. Ouvrez le fichier `index.html` dans n'importe quel navigateur web moderne (Chrome, Firefox, Safari, Edge).

## 🌍 Partage et Mise en ligne
Vous souhaitez partager cette application avec vos collègues ?
1. Utilisez une plateforme comme [Netlify Drop](https://app.netlify.com/drop).
2. Glissez-déposez votre dossier de projet sur le site de Netlify.
3. Obtenez votre lien URL unique et partagez-le instantanément sur WhatsApp, par email ou via vos réseaux sociaux.

## 💡 Conseils d'utilisation
- **Sauvegardez régulièrement :** Utilisez le bouton "Exporter Données" dans la section Configuration pour créer une copie de sécurité sur une clé USB ou un autre appareil.
- **Personnalisation :** N'oubliez pas d'aller dans la section "Configuration" dès la première utilisation pour renseigner le nom de votre pharmacie.

## 👤 À propos
Cette application a été développée pour être simple, rapide et accessible, permettant aux pharmaciens de se concentrer sur l'essentiel : le service aux patients.
